What Drover is

One workspace for every coding agent you run.

Drover is a desktop app for people who run several AI coding agents at once. It keeps them running in a background server, shows each one's state at a glance, and lets you answer, review and ship their work from one window, on any of your machines.

Agents
Claude CodeCodex CLIGemini CLIopencodeAny shell+ your own TOML rules
Runs on
Windows 10 / 11Linux x64 · arm64macOSPhone browserRemote servers over SSH

Knows who needs you

Every agent is marked working, needs you, done or idle. Drover reads it from the screen with TOML rules, or the agent reports it over OSC 7501. You get a desktop notification and an Inbox of everyone waiting.

⟳

Agents keep running

Close the window, they carry on in drover-server. Reopen and pick up where they are.

⇄

Agents run agents

dr run, wait, read and send work from inside any pane, so one agent can hand work to another.

⌥

Git worktree per task

Each task gets its own worktree. The Changes view shows the diff and lets you commit, push and open a PR.

✉

Chat view for Claude Code

Read Claude's work as a conversation with tool cards, approve permissions inline, switch model and how much it may do alone.

⌂

Every machine in one sidebar

Add a VPS with dr machine add. Its agents show up next to your local ones through an SSH tunnel.

▦

Splits, search, files

Split panes with VS Code keys, search across every agent's output, a file tree and code editor built in.

☐

Works on your phone

The same UI has a phone layout with a key strip for Esc, Tab, arrows and Ctrl+C. Open it over Tailscale.

≡

Plain-file config

Settings, keys, machines and detection rules are TOML files you can edit inside the app. Updates install from Settings.

Install

One file. No Python, no Node.

Drover ships as a single binary with the web UI built in. Pick your system.

# x64 or arm64, installs to ~/.local/share
$ curl -fsSL https://raw.githubusercontent.com/doquangthanh/drover-core/main/scripts/install.sh | sh

# pin a version
$ DROVER_VERSION=v0.2.15 sh install.sh

# open the window
$ drover
Puts
dr and drover in ~/.local/bin
Window
Native with GTK + WebKit. Without them, dr opens the UI in your browser.
Update
Settings → Check for updates, or run the same command again.
# recommended: paste into PowerShell. No "Windows protected your PC" warning
PS> irm https://raw.githubusercontent.com/doquangthanh/drover-core/main/scripts/install.ps1 | iex

Download
  1. Download Drover and save it anywhere you like, such as your Desktop.
  2. Open it. The first time, it fetches the rest of Drover (about 40 MB), then starts. There is no setup wizard.
  3. Downloaded in a browser, Windows may say it doesn't recognise the app. Click More info, then Run anyway, or use the PowerShell command above, which skips this.

Guide

From install to a working herd in five steps.

1

Start an agent

Press + in the tab bar or Ctrl+Shift+`. Pick the agent, the folder, an optional worktree and a first prompt.

agent claude folder ~/code/api tree task/auth-refactor prompt "split the session module" ▶ start
2

Close the window

Agents live in drover-server, not in the window. Close it, reboot the UI, come back tomorrow. They are still running.

$ dr status server running 127.0.0.1:47213 agents 4 ● 2 working ● 1 needs you
3

Answer whoever needs you

Drover reads each screen and marks it working, needs you, done or idle. F8 jumps straight to the next agent waiting on you.

● codex · flaky-tests Allow npm test -- --runInBand? [y] yes [a] always [n] no
4

Let agents run agents

Any pane can start, wait on, read and message the others with dr. Add dr skill to AGENTS.md so your agents know how.

$ dr run --bg --name tests -- codex $ dr wait tests --state done --timeout 900 done after 6m12s $ dr read tests --lines 40
5

Bring in your other machines

Remote daemons join the same sidebar over SSH. They listen on localhost only, and host keys are checked against known_hosts.

$ dr machine add vps-1 deploy@vps-1 --install installing uv + drover … ok tunnel 127.0.0.1:47213 → vps-1 connected
Reference

Keys and commands.

VS Code's default keys, and they reach Drover even inside a terminal. Ctrl+K W means press Ctrl+K, let go, then W.

Ctrl+Shift+P · Ctrl+K Ctrl+SAll commands / all shortcuts
